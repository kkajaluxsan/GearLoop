# Appendix A1 — Consent

Constraint **d** requires raw research data to be *retained and referenced*.
Consent is what makes retaining it legitimate. Record it for every participant,
before the session starts, before the recorder is running for research purposes.

---

## The script — read this aloud, verbatim

> I'm a student working on a design project for an app that lets people rent and
> swap sports equipment with each other. This is research, not a sales pitch — I
> didn't build it to be right, I built it to be tested, so please be blunt.
>
> It'll take about **[30 / 45]** minutes. I'd like to record the audio so I don't
> have to write while you're talking, and **[for walkthrough sessions]** record
> the phone screen — not you, just the screen.
>
> I'll use it only for this assignment. Your full name won't appear anywhere; you'll
> be a code like "P3". You can stop at any point, skip any question, or ask me to
> delete the recording afterwards and I will, no reason needed.
>
> **Is that alright? And is it alright to record?**

Wait for an explicit yes. A nod is not consent on a recording.

**For walkthrough sessions, add:**

> One more thing — I'm testing the design, not you. Nothing you do here can be
> wrong. If something is confusing, that's the design's fault and it's exactly
> what I need to find. Please think out loud, and if you ask me a question I'll
> probably ask what you think first. That's not me being rude, it's the method.

## If someone declines to be recorded

Do the session anyway and take written notes. Mark the participant's rows in
[A2](A2-participant-log.md) as **notes only**, and mark their quotes in
[`01-research-data.md`](../01-research-data.md) as *reconstructed from notes*
rather than verbatim. A reconstructed quote is still evidence; a reconstructed
quote presented as verbatim is not.

## Data handling

- Recordings live in `raw/` and are **not committed to git** — see that folder's
  note.
- Participants are referred to by code (P1–P7) everywhere in the report body.
- No full names, phone numbers or addresses appear in any file in this folder.
- Delete the recordings once the module result is confirmed, unless a participant
  has asked for them to go sooner.
